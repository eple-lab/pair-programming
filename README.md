# pair-programming
게임 만들기 페어프로그래밍

## PRD
[PRD] 지렁이게임 기획서
1. 한 줄 소개
어떤 게임인가?: 2D 실시간 지렁이 생존/성장 게임

2. 누가 (타겟 유저)
플레이어: 가볍고 단순한 조작으로 순발력과 집중력을 즐기고 싶은 모든 웹/모바일 게임 유저

3. 규칙과 끝나는 조건
게임 진행 방식:
- 플레이어는 지렁이를 조종한다. (지렁이를 조작해서 먹이를 획득한다.)
- 조종은 마우스, 키보드로 둘다 가능하다.
- 넓은 맵에 여러 AI 지렁이가 돌아다닌다.
- 빛나는 먹이를 먹으면 지렁이가 성장한다.
- 다른 지렁이의 몸통에 머리가 충돌하면 죽는다.
- 죽은 지렁이는 자신의 몸 길이에 비례하는 먹이를 남긴다.
- 다른 지렁이가 남긴 먹이를 먹으면 빠르게 성장한다.
- 가속 기능을 사용하면 빠르게 움직이지만 몸 길이가 감소한다.
- 최대한 오래 살아남아 길이와 점수를 높이는 것이 목표다.

끝나는 조건:
-->
- 제한 시간 모드 (5분)
- 다른 지렁이 몸통에 머리 충돌	플레이어 사망		GAME OVER
  	경기

4. 맵
- 벽이 없다. 맵 끝에 닿아서 죽는 일은 없다.
- 맵은 화면보다 훨씬 넓고 끝없이 이어진다. 어느 방향으로 가도 먹이와 AI 지렁이가 계속 나타난다.
- 맵 끝이 없으므로 미니맵 대신 플레이어 중심 레이더로 주변 지렁이 위치를 보여준다.

5. 점수
| 먹이 | 획득 점수 | 성장 | 비고 |
|---|---|---|---|
| 일반 먹이 | 10점 | +1 | 맵에 흩어져 빛나는 먹이 |
| 황금 먹이 | 50점 | +3 | 금색으로 더 크게 빛남, 새로 생기는 먹이의 약 5% |
| 죽은 지렁이가 남긴 먹이 | 10점 | +3 | 크게 표시, 빠르게 성장 |
| 가속 중 흘린 먹이 | 10점 | +1 | |

- 점수는 먹은 먹이의 점수를 합산한다. (길이와 별개)
- 리더보드는 점수 순으로 정렬한다.

6. 조작
- 마우스: 커서 방향으로 이동, 클릭 유지 시 가속
- 키보드: 방향키/WASD로 이동, Space 유지 시 가속
- 모바일: 화면 터치 방향으로 이동, 가속 버튼

7. 게임 종료
| 조건 | 결과 |
|---|---|
| 제한 시간 5분 종료 | TIME UP |
| 다른 지렁이 몸통에 머리 충돌 | GAME OVER |

- 종료 화면에 점수, 최대 길이, 처치 수, 생존 시간, 최고 기록을 표시한다.
