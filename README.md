게임 만들기 페어프로그래밍

## PRD
[PRD] 지렁이게임 기획서
1. 한 줄 소개
어떤 게임인가?: 2D 실시간 지렁이 생존/성장 게임

2. 누가 (타겟 유저)
플레이어: 가볍고 단순한 조작으로 순발력과 집중력을 즐기고 싶은 모든 웹/모바일 게임 유저

3. 규칙과 끝나는 조건
게임 진행 방식:
- 플레이어는 지렁이를 조종한다. (지렁이를 조작해서 먹이를 획득한다.)
- 조종은 마우스, 키보드로 둘다 가능하다.
- 넓은 맵에 여러 AI 지렁이가 돌아다닌다.
- 빛나는 먹이를 먹으면 지렁이가 성장한다.
- 다른 지렁이의 몸통에 머리가 충돌하면 죽는다.
- 죽은 지렁이는 자신의 몸 길이에 비례하는 먹이를 남긴다.
- 다른 지렁이가 남긴 먹이를 먹으면 빠르게 성장한다.
- 가속 기능을 사용하면 빠르게 움직이지만 몸 길이가 감소한다.
- 최대한 오래 살아남아 길이와 점수를 높이는 것이 목표다.
